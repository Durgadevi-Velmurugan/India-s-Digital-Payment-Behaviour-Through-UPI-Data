#India's Digital Payment Behaviour Through UPI Data

##Project Overview

This project analyses UPI transaction data published by NPCI to understand how India makes digital payments. It uses Python for data cleaning , exploratory data analysis (EDA),and uses Power BI for data visualization.

##Objectives

-Identify top states and districts by UPI usage.

-Compare person to person (P2P) and person to merchant(P2M) payments.

-Find which UPI apps lead the market.

-Understand which merchant categories get the most spending
